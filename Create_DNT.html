왜 이 세 가지 도구를 사용했나요?
구글 시트 — 별도 데이터베이스 없이 엑셀처럼 데이터를 관리할 수 있고, 과정이 바뀌어도 시트만 업데이트하면 됩니다.
Apps Script — 구글 시트와 같은 생태계라 연결이 간단하고, 별도 서버 없이 데이터를 주고받는 API를 무료로 만들 수 있습니다.
GitHub Pages — HTML 파일 하나를 올리면 누구나 접속 가능한 링크가 무료로 생성됩니다. 앱 배포나 서버 운영 없이 바로 공유할 수 있습니다.
세 가지 모두 무료이고, 설정이 최소화되어 있으며, 유지보수가 간단합니다.
🔒
참가자는 구글 시트에 직접 접근할 수 없습니다
참가자 화면에는 Apps Script 주소만 노출되고, 그 뒤에 시트가 있다는 것조차 알 수 없습니다. 식당 손님이 주방에 직접 들어갈 수 없는 것처럼 — 데이터는 명찰 페이지 → Apps Script → 구글 시트 순서로만 전달되며, 구글 시트는 담당자 계정으로만 접근 가능합니다.
단계별 만드는 방법
01

구글 시트에 참가자 정보 입력

명찰에 표시될 모든 내용이 여기서 시작됩니다

📊
✏️
1행에 항목 이름(헤더)을 넣고, 2행부터 참가자 한 명당 한 줄씩 입력합니다.
이름, 사번, 직급, 소속, 과정명, 반/팀 등 명찰에 필요한 정보를 모두 담으면 됩니다.
⚠️
개인 민감 정보는 기입하지 마세요.
주민등록번호, 연락처, 주소 등 민감한 개인 정보는 이 시트에 입력하지 않습니다. 직무 관련 정보(이름·사번·소속·직급)만 사용합니다.
🔐
S열 — 패스코드 에 4자리 숫자를 입력하면 대강당 출결 버튼이 자동으로 활성화됩니다. 비워두면 버튼이 아예 표시되지 않습니다.
⏺️
T열 — 출결시간 은 참가자가 출결을 완료하면 시스템이 자동으로 채워줍니다. 담당자가 따로 입력할 필요가 없습니다.
🤖
CLAUDE 활용 팁
필요한 항목을 먼저 정리한 뒤, 구조 검토용으로 활용해보세요 "내가 이름·사번·소속·과정명·반·팀·출결을 관리하려는데, 시트 헤더 순서 이렇게 하면 괜찮을까?" "S열 패스코드, T열 출결시간으로 쓰려는데 문제 없어?"
02

Apps Script로 연결 코드 만들기

구글 시트 데이터를 명찰 페이지에 전달하는 역할

⚙️
🖱️
구글 시트 상단 메뉴에서 확장 프로그램 → Apps Script를 클릭합니다.
📋
제공된 코드를 그대로 붙여넣기 합니다. 코드는 두 가지 일을 합니다.
① 사번으로 참가자 정보 찾기
② 출결 완료 시 시트에 시간 자동 기록
🚀
우측 상단 배포 → 새 배포를 눌러 웹 주소(URL)를 발급받습니다.
이 주소가 명찰 페이지와 구글 시트를 연결하는 다리 역할을 합니다.
⚠️
코드를 수정했다면 반드시 새 버전으로 다시 배포해야 반영됩니다.
🤖
CLAUDE 활용 팁
어떤 동작이 필요한지 설명하면, 코드 작성은 Claude가 담당합니다 "사번을 받아서 시트에서 해당 참가자 정보를 찾아 반환하는 Apps Script 코드가 필요해" "출결 완료 시각을 한국 시간 기준으로 T열에 기록하게 해줘"
03

GitHub Pages로 명찰 페이지 공개

링크만 있으면 누구나 접속할 수 있게 올려두는 과정

🌐
📁
GitHub 저장소에 index.html 파일을 올립니다.
파일 안에 2단계에서 받은 Apps Script 주소를 붙여넣으면 연결 완료입니다.
⚙️
저장소 설정(Settings) → Pages → Branch: main 선택 후 저장.
잠시 후 접속 가능한 고정 URL이 자동 생성됩니다.
✅
과정이 바뀌어도 index.html을 다시 올릴 필요 없습니다.
구글 시트의 데이터만 수정하면 명찰 내용이 자동으로 반영됩니다.
🤖
CLAUDE 활용 팁
원하는 기능과 화면 구성을 설명하면 코드로 구현해줍니다 "사번 입력 시 구글 시트에서 명찰 정보를 불러오는 HTML 페이지가 필요해" "버튼 색을 LG 브랜드 빨간색 계열로 바꿔줘" "식권 버튼은 누르면 가로화면으로 크게 표시되어야 해"
04

참가자에게 링크 공유

앱 설치 없이 스마트폰 브라우저에서 바로 사용

📲
📤
GitHub Pages에서 생성된 URL을 QR코드나 문자/이메일로 참가자에게 공유합니다.
📱
참가자는 링크를 열고 사번만 입력하면 본인 명찰이 바로 표시됩니다.
설치할 앱도 없고, 로그인도 필요 없습니다.

출결이 완료되면 구글 시트 T열에 시각이 자동 기록됩니다.
담당자는 시트에서 실시간으로 출결 현황을 확인할 수 있습니다.

🤖
CLAUDE 활용 팁
추가 기능이 필요할 때도 어떤 동작인지 설명하면 됩니다 "출결이 이미 완료된 경우 버튼이 초록색으로 바뀌고 클릭이 안 되게 해줘" "명찰이 뜨면 출결을 안내하는 팝업이 먼저 표시됐으면 좋겠어" "IT 문의 버튼은 로그인 정보가 있는 참가자에게만 보이게 해줘"
